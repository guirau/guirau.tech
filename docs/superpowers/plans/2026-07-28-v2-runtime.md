# v2 Robot Runtime (Plan 2 of 3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Three.js runtime — scene, rig binding, the four behaviours, the 3.5s intro sequence and every degradation path — verified against a **placeholder mesh built from primitives**, so no part of it waits on asset generation.

**Architecture:** Behaviours are **pure functions** of the shape `(time, inputState) → pose delta`. They never touch the scene graph. A single `applyPose()` in `pose.js` is the only writer to any `Object3D`, which structurally prevents two systems fighting over `head.rotation.y`. That purity is also what makes the whole thing testable in `node:test` without a WebGL context: the maths runs in Node, and only the compositing needs a browser.

**Tech Stack:** Three.js (vendored via esbuild into a committed `app.js`), `node:test` for pure-function unit tests, Playwright for compositing and degradation, `@gltf-transform/cli` for GLB compression.

## Scope Check

This is Plan 2 of the three-way split described in `docs/superpowers/plans/2026-07-28-v2-page.md`. It depends on Plan 1's page shell (the `.stage` element, the tokens, the marquee) but **not** on Plan 3's generated robot.

**The decoupling that makes this work:** spec §4.1 defines the Blender→Three.js contract as a *named node hierarchy*, not a particular mesh. Anything exposing `Root/Torso/Neck/Head/Shoulder_{L,R}/Forearm_{L,R}/Hand_{L,R}` satisfies `rig.js`. Task 3 builds exactly that out of boxes and spheres. Every behaviour, the intro, the degradation table and the whole test suite are therefore written and verified before a single generation credit is spent, and Plan 3's final act is a file swap plus a calibration pass.

**What genuinely cannot be finished here:** spec open item 6 — `F`, `yFace` and `zFace` are measurements *of a helmet that does not exist yet*. Task 8 defines them as named constants in one file with the placeholder's values, and Plan 3 Task 7 re-measures them. Nothing else in this plan reads those numbers directly.

### `[tune]` pairs owned by this plan

| Pair | Task | Why coupled |

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { readFileSync, statSync, readdirSync } from 'node:fs';
import { join } from 'node:path';

const root = new URL('../../', import.meta.url).pathname;

test('app.js is marked generated and names its build command', () => {
  const head = readFileSync(join(root, 'assets/app.js'), 'utf8').slice(0, 400);
  assert.match(head, /GENERATED FILE/);
  assert.match(head, /npm run build/);
});

// Local-dev guard, not a deploy gate: git rewrites only files whose content
// changes on checkout, so a branch switch can make src/ look newer than a
// byte-identical bundle. If this fires right after a checkout or stash pop,
// run npm run build once - a no-diff rebuild clears the false alarm.
test('app.js is newer than every source file it is built from', () => {
  const bundle = statSync(join(root, 'assets/app.js')).mtimeMs;

  const walk = (dir) => readdirSync(dir, { withFileTypes: true }).flatMap((e) => {
    const p = join(dir, e.name);
    return e.isDirectory() ? walk(p) : /\.m?js$/.test(p) ? [p] : [];
  });

  const stale = walk(join(root, 'src'))
    .filter((f) => !f.endsWith('placeholder.js'))   // dev-only, not bundled
    .filter((f) => statSync(f).mtimeMs > bundle);

  assert.deepEqual(stale, [],
    `these sources are newer than the committed bundle — run npm run build:\n${stale.join('\n')}`);
});
```

```js
// Framing maths. Pure — no Three.js, no DOM. Everything here is testable in Node.

const rad = (deg) => (deg * Math.PI) / 180;

/**
 * Distance at which a subject of `subjectSize` world units exactly fills the frame.
 *
 * Math.min(aspect, 1) is the whole trick: on a canvas narrower than it is tall,
 * fitting by height alone would crop the sides, so the camera retreats until the
 * subject fits by width too. That is precisely `object-fit: contain` on a square
 * image, which is what the face plane is.
 */
export function faceDistance({ subjectSize, fov, aspect }) {
  return subjectSize / (2 * Math.tan(rad(fov) / 2) * Math.min(aspect, 1));
}

// Frozen deep: these are shared singletons returned by reference, and a
// caller mutating .position would silently corrupt every later call.
const FULL_BODY = Object.freeze({
  name: 'full-body',
  position: Object.freeze([0, 1.00, 3.50]),
  lookAt: Object.freeze([0, 1.00, 0]),
});
const CHEST_UP = Object.freeze({
  name: 'chest-up',
  position: Object.freeze([0, 1.45, 1.50]),
  lookAt: Object.freeze([0, 1.45, 0]),
});

/** Short viewports cannot fit a 1.8-unit figure without shrinking it to nothing. */
export const SHORT_VIEWPORT_PX = 620;

export function chooseEndFraming(viewportHeight) {
  return viewportHeight < SHORT_VIEWPORT_PX ? CHEST_UP : FULL_BODY;
}

/**
 * Off-centre bias in WORLD units.
 *
 * kx/ky are fractions of the visible frustum, not fixed offsets — so the robot
 * sits at the same fraction of the screen regardless of camera distance or
 * canvas size. A fixed world offset would drift across the dolly.
 */
export function frustumBias({ kx, ky, fov, distance, canvasW, canvasH }) {
  const visibleH = 2 * Math.tan(rad(fov) / 2) * distance;
  const visibleW = visibleH * (canvasW / canvasH);
  return { x: -kx * visibleW, y: -ky * visibleH };
}

/** Breakpoint-matched bias fractions. Values tuned in Plan 2 Task 12. */
export function biasFractions(viewportWidth) {
  return viewportWidth >= 900 ? { kx: 0.12, ky: 0.10 } : { kx: 0, ky: 0.06 };
}
```

```js
// A stand-in robot built from primitives, satisfying the spec §4.1 NAMING
// contract: Root > Torso > { Neck > Head, Shoulder_{L,R} > Forearm_{L,R} > Hand_{L,R} }
// facing +Z. Dimensions are approximate (~1.91 units tall, feet near y=0);
// the real GLB is numerically normalized to 1.8 by Plan 3's split gate.
//
// Dev-only: excluded from the bundle. Its purpose is to let the runtime, the
// behaviours and every test be written and verified before the real GLB exists.
import * as THREE from 'three';

const shell = () => new THREE.MeshStandardMaterial({
  color: 0x0a0a0c, roughness: 0.25, metalness: 0.6,
});

function part(name, geometry, position) {
  const mesh = new THREE.Mesh(geometry, shell());
  mesh.name = `${name}_Mesh`;
  const node = new THREE.Object3D();
  node.name = name;
  node.position.set(...position);
  node.add(mesh);
  return node;
}

export function buildPlaceholder() {
  const root = new THREE.Object3D();
  root.name = 'Root';

  // Torso: shoulder-to-waist taper, chest centred at y=1.20.
  const torso = part('Torso', new THREE.CylinderGeometry(0.16, 0.11, 0.62, 16), [0, 1.20, 0]);
  root.add(torso);

  // Legs are static — no behaviour touches them, so they need no named nodes.
  const legs = new THREE.Mesh(
    new THREE.CylinderGeometry(0.11, 0.09, 0.90, 12), shell()
  );
  legs.name = 'Legs_Mesh';
  legs.position.set(0, -0.76, 0);
  torso.add(legs);

  // Neck > Head. Head origin sits at the neck joint so rotation pivots correctly.
  const neck = part('Neck', new THREE.CylinderGeometry(0.055, 0.065, 0.10, 12), [0, 0.34, 0]);
  torso.add(neck);

  const head = new THREE.Object3D();
  head.name = 'Head';
  head.position.set(0, 0.08, 0);
  const helmet = new THREE.Mesh(new THREE.SphereGeometry(0.135, 24, 20), shell());
  helmet.name = 'Head_Mesh';
  helmet.scale.set(1, 1.18, 1.05);   // egg form
  helmet.position.y = 0.12;
  head.add(helmet);
  neck.add(head);

  // Arms, both sides. Wide A-pose: clear gaps at the armpits, elbows straight.
  for (const [suffix, sign] of [['L', 1], ['R', -1]]) {
    const shoulder = part(`Shoulder_${suffix}`,
      new THREE.CapsuleGeometry(0.045, 0.24, 4, 8), [sign * 0.20, 0.24, 0]);
    shoulder.rotation.z = sign * -0.28;
    torso.add(shoulder);

    const forearm = part(`Forearm_${suffix}`,
      new THREE.CapsuleGeometry(0.038, 0.22, 4, 8), [0, -0.28, 0]);
    shoulder.add(forearm);

    const hand = part(`Hand_${suffix}`,
      new THREE.BoxGeometry(0.07, 0.11, 0.045), [0, -0.20, 0]);
    forearm.add(hand);
  }

  return root;
}
```

```js
import { buildPlaceholder } from '../robot/placeholder.js';

// Node has no FileReader (browser-only global). GLTFExporter's binary path

if (typeof globalThis.FileReader === 'undefined') {

    readAsArrayBuffer(blob) {

const exporter = new GLTFExporter();
const glb = await new Promise((resolve, reject) =>
```

```js
// A minimal stand-in for an Object3D tree — bindRig must not need Three.js.
const node = (name, children = []) => ({
  name,
  children,
  traverse(fn) { fn(this); this.children.forEach((c) => c.traverse(fn)); },

const completeTree = () => node('Root', [

    node('Neck', [node('Head')]),
    node('Shoulder_L', [node('Forearm_L', [node('Hand_L')])]),
    node('Shoulder_R', [node('Forearm_R', [node('Hand_R')])]),
  ]),
]);

test('binds all ten contract nodes by name', () => {
  const rig = bindRig(completeTree());
  for (const name of REQUIRED_NODES) {
    assert.equal(rig[name].name, name, `${name} must be bound`);
  }
```

```js
// Binds the named nodes that the Blender split (spec §4.2) produces.
// Duck-typed on `traverse` and `name`, so it works with a real Object3D and
// with a plain test double — no Three.js import, no WebGL needed to test it.

export const REQUIRED_NODES = Object.freeze([
  'Root', 'Torso', 'Neck', 'Head',
  'Shoulder_L', 'Forearm_L', 'Hand_L',
  'Shoulder_R', 'Forearm_R', 'Hand_R',
]);

/**
 * Thrown when the loaded model does not satisfy the §4.1 contract.
 * Spec §7 catches this specifically: it is the switch into unsplit-mesh mode,
 * where the whole robot yaws as one piece instead of articulating.
 */
export class RigError extends Error {
  constructor(missing) {
    super(`Rig contract not satisfied — missing node(s): ${missing.join(', ')}`);
    this.name = 'RigError';
    this.missing = missing;
  }
}

/** Thrown when the same contract name appears twice — a split that went wrong. */
export class DuplicateNodeError extends Error {
  constructor(names) {
    super(`Rig has duplicate node name(s): ${names.join(', ')}`);
    this.name = 'DuplicateNodeError';
    this.duplicates = names;
  }
}

export function bindRig(root) {
  const found = new Map();
  const duplicates = new Set();

  root.traverse((node) => {
    if (!REQUIRED_NODES.includes(node.name)) return;
    if (found.has(node.name)) duplicates.add(node.name);
    else found.set(node.name, node);
  });

  // Duplicates first: a last-wins bind would silently animate the wrong mesh,
  // which is far harder to diagnose than an outright failure.
  if (duplicates.size) throw new DuplicateNodeError([...duplicates]);

  const missing = REQUIRED_NODES.filter((n) => !found.has(n));
  if (missing.length) throw new RigError(missing);

  return Object.freeze(Object.fromEntries(found));
}
```

```js
// The ONLY writer to the scene graph.
//
// Behaviours are pure: each returns a plain object of per-node rotation deltas
// and touches nothing. This module sums them and writes once per frame. That is
// what stops idle sway and cursor-follow from fighting over head.rotation.y —
// they are not competing writers, they are two addends.

const AXES = { rx: 'x', ry: 'y', rz: 'z' };

export const EMPTY_POSE = Object.freeze({});

/** Sum any number of pose fragments. Inputs are never mutated. */
export function composePose(fragments) {
  const out = {};

  for (const fragment of fragments) {
    if (!fragment) continue;
    for (const [nodeName, delta] of Object.entries(fragment)) {
      const target = (out[nodeName] ??= { rx: 0, ry: 0, rz: 0 });
      for (const key of Object.keys(AXES)) {
        if (delta[key] !== undefined) target[key] += delta[key];
      }
    }
  }

  return out;
}

/**
 * Snapshot the rig's rest rotations. Call once, straight after bindRig, before
 * any behaviour has run — this is the pose deltas are measured *from*.
 */
export function captureRest(rig) {
  const rest = {};
  for (const [nodeName, node] of Object.entries(rig)) {
    const { x, y, z } = node.rotation;
    rest[nodeName] = Object.freeze({ x, y, z });
  }
  return Object.freeze(rest);
}

/**
 * Write a composed pose onto the rig, as an offset from the rest pose.
 *
 * Every axis of every addressed node is written, including the ones the pose
 * left at zero — otherwise a behaviour that stops contributing (blink ending,
 * lookAt disabled on touch) leaves its last rotation frozen into the model.
 * Zero means "back to rest", which is why `rest` is added rather than assumed
 * to be identity: the A-pose is a non-zero shoulder rotation.
 *
 * Missing nodes are skipped rather than thrown on, because unsplit-mesh mode
 * (§7) runs the same behaviours against a rig with only Root bound.
 */
export function applyPose(rig, pose, rest = EMPTY_POSE) {
  for (const [nodeName, delta] of Object.entries(pose)) {
    const node = rig[nodeName];
    if (!node) continue;
    const base = rest[nodeName];
    for (const [key, axis] of Object.entries(AXES)) {
      node.rotation[axis] = (base?.[axis] ?? 0) + (delta[key] ?? 0);
    }
  }
}
```

```js
// Idle sway. Pure: (time) -> pose deltas.
//
// The three frequencies are deliberately incommensurate (spec §6.3). Their
// ratios do not reduce to small integers, so the combined motion has no short
// common period and never reads as a loop.
export const IDLE_FREQUENCIES = Object.freeze({
  torso: 0.23,
  shoulders: 0.31,
  head: 0.17,
});

const AMPLITUDE = Object.freeze({
  torso: 0.018,
  shoulders: 0.022,
  head: 0.012,
});

const wave = (t, hz) => Math.sin(2 * Math.PI * hz * t);

export function idlePose(time) {
  const torso     = wave(time, IDLE_FREQUENCIES.torso);
  const shoulders = wave(time, IDLE_FREQUENCIES.shoulders);
  const head      = wave(time, IDLE_FREQUENCIES.head);

  return {
    Torso:      { ry: AMPLITUDE.torso * torso, rz: AMPLITUDE.torso * 0.4 * torso },
    // Mirrored: the arms breathe outward together rather than swinging in parallel.
    Shoulder_L: { rz: AMPLITUDE.shoulders * shoulders },
    Shoulder_R: { rz: -AMPLITUDE.shoulders * shoulders },
    Head:       { rx: AMPLITUDE.head * head },
  };
}
```

```js
// Blink. Pure: (time, blinkStartTime) -> { eyeScale, emissive }.
//
// Returns NO pose fragment. There is no eyelid bone in the §4.1 contract, so
// the blink is expressed entirely as a material uniform and a mesh scale that
// main.js applies to the visor's eye elements. Keeping it out of the rig means
// it can never collide with idle or lookAt.

export const BLINK_DURATION_S = 0.12;

const MIN_GAP_S = 2;
const MAX_GAP_S = 6;

/** Deterministic hash so a given index always yields the same gap. */
function pseudoRandom(index) {
  const x = Math.sin(index * 12.9898 + 78.233) * 43758.5453;
  return x - Math.floor(x);
}

export function nextBlinkTime(currentTime, index) {
  return currentTime + MIN_GAP_S + pseudoRandom(index) * (MAX_GAP_S - MIN_GAP_S);
}

export function blinkState(time, blinkStartTime) {
  const elapsed = time - blinkStartTime;
  if (elapsed < 0 || elapsed > BLINK_DURATION_S) return { eyeScale: 1, emissive: 1 };

  // Symmetric close-open: 0 at the ends, 1 at the midpoint.
  const closed = Math.sin((elapsed / BLINK_DURATION_S) * Math.PI);
  const open = 1 - closed;
  return { eyeScale: open, emissive: open };
}
```

```js
// Cursor-follow. Pure: (state, target, dt) -> { state, pose }.
//
// Critically damped spring (zeta = 1): the head arrives and STOPS. An
// underdamped spring would overshoot and wobble back, which reads as a servo
// hunting rather than as attention.

export const LOOK_LIMITS = Object.freeze({ yaw: 22, pitch: 14 });

const OMEGA = 6;                 // rad/s — settles in roughly a second
const TORSO_COUNTER = 0.30;      // §6.4: torso follows at 30% of neck yaw

const toRad = (deg) => (deg * Math.PI) / 180;
const clamp = (v, limit) => Math.max(-limit, Math.min(limit, v));

export function createLookAtState() {
  return { yaw: 0, pitch: 0, yawVel: 0, pitchVel: 0 };
}

/**
 * One critically damped step. The acceleration form
 *   a = -2*w*v - w^2*(x - target)
 * integrated semi-implicitly is stable at any dt we will see, which is why the
 * 30fps and 120fps paths converge to the same pose.
 */
function spring(position, velocity, target, dt) {
  const accel = -2 * OMEGA * velocity - OMEGA * OMEGA * (position - target);
  const nextVelocity = velocity + accel * dt;
  return { position: position + nextVelocity * dt, velocity: nextVelocity };
}

/** `target` is normalized pointer position in [-1, 1] on both axes. */
export function stepLookAt(state, target, dt) {
  const targetYaw = clamp(target.x, 1) * toRad(LOOK_LIMITS.yaw);
  const targetPitch = clamp(-target.y, 1) * toRad(LOOK_LIMITS.pitch);

  const yaw = spring(state.yaw, state.yawVel, targetYaw, dt);
  const pitch = spring(state.pitch, state.pitchVel, targetPitch, dt);

  const nextState = {
    yaw: clamp(yaw.position, toRad(LOOK_LIMITS.yaw)),
    pitch: clamp(pitch.position, toRad(LOOK_LIMITS.pitch)),
    yawVel: yaw.velocity,
    pitchVel: pitch.velocity,
  };

  return {
    state: nextState,
    pose: {
      Neck: { ry: nextState.yaw, rx: nextState.pitch },
      Torso: { ry: nextState.yaw * TORSO_COUNTER },
    },
  };
}
```

```js
// The intro sequence. Pure: (t) -> { cameraT, faceOpacity, visorOpacity, biasT }.
//
// Camera travel and both opacities are read from ONE clock, so they cannot
// drift apart the way three independent tweens would.
//
// 3.5s total, deliberately under the WCAG 2.2.2 (Pause, Stop, Hide) five-second
// threshold — above it, a gated intro would need a pause control.

export const INTRO_DURATION_S = 3.5;
export const MARQUEE_REVEAL_S = 0.4;

/** Spec §6.1 phase table. Camera fractions are of total travel. */
const PHASES = Object.freeze([
  { name: 'face',  start: 0.00, end: 0.60, camera: [0.00, 0.00], face: [1.00, 1.00], visor: [0.00, 0.00] },
  { name: 'visor', start: 0.60, end: 1.80, camera: [0.00, 0.60], face: [1.00, 1.00], visor: [0.00, 0.80] },
  { name: 'recede',start: 1.80, end: 2.70, camera: [0.60, 0.88], face: [1.00, 0.70], visor: [0.80, 0.90] },
  { name: 'settle',start: 2.70, end: 3.50, camera: [0.88, 1.00], face: [0.70, 0.70], visor: [0.90, 0.92] },
]);

export const SETTLED_STATE = Object.freeze({
  cameraT: 1, faceOpacity: 0.70, visorOpacity: 0.92, biasT: 1,
});

const lerp = (a, b, t) => a + (b - a) * t;
const easeInOut = (t) => (t < 0.5 ? 2 * t * t : 1 - ((-2 * t + 2) ** 2) / 2);

/**
 * cubic-bezier(0.16, 1, 0.3, 1) — Apple's expo-out.
 *
 * It front-loads almost all of its travel, which is why it is scoped to the
 * 0.8s settle rather than the whole sequence: applied across 3.5s it would put
 * the camera at its end position before the face-hold beat had finished.
 */
function expoOut(t) {
  // Closed-form approximation adequate for an 0.8s visual settle.
  return t >= 1 ? 1 : 1 - (2 ** (-10 * t));
}

export function introState(time) {
  const t = Math.max(0, Math.min(time, INTRO_DURATION_S));

  const phase = PHASES.find((p) => t < p.end) ?? PHASES[PHASES.length - 1];
  const span = phase.end - phase.start;
  const local = span === 0 ? 1 : Math.min(1, (t - phase.start) / span);

  const eased = phase.name === 'settle' ? expoOut(local)
              : phase.name === 'face'   ? local
              : easeInOut(local);

  return {
    phase: phase.name,
    cameraT: lerp(phase.camera[0], phase.camera[1], eased),
    faceOpacity: lerp(phase.face[0], phase.face[1], eased),
    visorOpacity: lerp(phase.visor[0], phase.visor[1], eased),
    // Bias must be zero at t=0 or the face starts off-centre; it ramps across
    // B-D and finishes with the camera.
    biasT: lerp(phase.camera[0], phase.camera[1], eased),
  };
}

/**
 * How much of the face actually reaches the viewer.
 *
 * Multiplicative: the face plane's own opacity, times what the visor lets
 * through. The PRODUCT is the specified value (~5%, gate [0.04, 0.07]) — the
 * two inputs must never be tuned independently, because trading one against
 * the other preserves the number and destroys the look.
 */
export function contribution({ faceOpacity, visorOpacity }) {
  return faceOpacity * (1 - visorOpacity);
}
```

```js
// The face plane and the visor, both parented to the Head node.
//
// Parenting is the whole registration strategy: once the plane is a child of
// Head, it inherits every transform the camera dolly and lookAt produce for
// free. The alternative — projecting to screen space each frame — would need
// to re-derive the same maths and would drift under any rig change.
import * as THREE from 'three';

export const VIGNETTE_INNER = 0.58;
export const VIGNETTE_OUTER = 0.95;

/**
 * Alpha as a function of normalized radius.
 *
 * r is 1.0 at the plane's edge MIDPOINTS and 1.41 at its CORNERS. The amber
 * backdrop only survives the §4.5 crop in the upper corners, so a falloff that
 * finishes at 0.95 removes it at zero cost to the face — while simultaneously
 * dissolving the hard letterbox edge a square plane shows in a wide viewport.
 * One mechanism, two jobs. Tune it together with the crop, never alone.
 */
export function vignetteAlpha(r) {
  if (r <= VIGNETTE_INNER) return 1;
  if (r >= VIGNETTE_OUTER) return 0;
  const t = (r - VIGNETTE_INNER) / (VIGNETTE_OUTER - VIGNETTE_INNER);
  return 1 - (t * t * (3 - 2 * t));   // smoothstep
}

const VERTEX = /* glsl */`
  varying vec2 vUv;
  void main() {
    vUv = uv;
    gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
  }
`;

const FRAGMENT = /* glsl */`
  uniform sampler2D uMap;
  uniform float uFaceOpacity;
  varying vec2 vUv;

  void main() {
    vec4 tex = texture2D(uMap, vUv);
    float r = length(vUv - 0.5) * 2.0;           // 1.0 at edge midpoints, 1.41 at corners
    float edge = 1.0 - smoothstep(${VIGNETTE_INNER.toFixed(2)}, ${VIGNETTE_OUTER.toFixed(2)}, r);
    gl_FragColor = vec4(tex.rgb, tex.a * edge * uFaceOpacity);
  }
`;

/** Picks the portrait size that matches the device's rendered resolution. */
export function pickFaceTexture(canvasHeight, dpr) {
  const needed = canvasHeight * Math.min(dpr, 2);
  if (needed <= 512) return 'assets/face-512.jpg';
  if (needed <= 1024) return 'assets/face-1024.jpg';
  return 'assets/face-1536.jpg';
}

/**
 * Builds the face plane and the visor and parents both to `head`.
 * `faceSize` is F — the world height of the face in model units.
 */
export function buildFace({ head, texture, faceSize, yFace, zFace }) {
  const faceMaterial = new THREE.ShaderMaterial({
    uniforms: { uMap: { value: texture }, uFaceOpacity: { value: 1 } },
    vertexShader: VERTEX,
    fragmentShader: FRAGMENT,
    transparent: true,
    depthWrite: false,
  });

  const face = new THREE.Mesh(new THREE.PlaneGeometry(faceSize, faceSize), faceMaterial);
  face.name = 'FacePlane';
  face.position.set(0, yFace, zFace);
  face.renderOrder = 1;

  const visorMaterial = new THREE.MeshStandardMaterial({
    color: 0x05050a,
    roughness: 0.18,
    metalness: 0.35,
    transparent: true,
    opacity: 0,
  });

  const visor = new THREE.Mesh(new THREE.PlaneGeometry(faceSize * 1.02, faceSize * 1.02), visorMaterial);
  visor.name = 'Visor';
  visor.position.set(0, yFace, zFace + 0.004);   // just in front of the face
  visor.renderOrder = 2;

  head.add(face, visor);
  return { face, visor, faceMaterial, visorMaterial };
}

export function setFaceOpacity({ faceMaterial, visorMaterial }, faceOpacity, visorOpacity) {
  faceMaterial.uniforms.uFaceOpacity.value = faceOpacity;
  visorMaterial.opacity = visorOpacity;
}
```

```js
    rig = bindRig(model);
  } catch (error) {
    if (!(error instanceof RigError)) throw error;
    console.warn(`${error.message} — running in unsplit-mesh mode`);
    unsplit = true;
    rig = { Root: model, Head: model };
  }
  window.__unsplitMode = unsplit;

  // Snapshot the rest pose BEFORE any behaviour runs. Deltas are offsets from
  // this, so the A-pose survives the first frame instead of being overwritten.
  const rest = captureRest(rig);

  const texture = await new THREE.TextureLoader()
    .loadAsync(pickFaceTexture(innerHeight, devicePixelRatio));
  texture.colorSpace = THREE.SRGBColorSpace;

  const faceParts = buildFace({
    head: rig.Head,
    texture,
    faceSize: FACE_CALIBRATION.F,
    yFace: unsplit ? FACE_CALIBRATION.yFace : 0.10,
    zFace: FACE_CALIBRATION.zFace,
  });

  let endFraming = chooseEndFraming(innerHeight);
  let needsResize = true;

  const resize = () => {
    const w = innerWidth;
    const h = innerHeight;
    renderer.setSize(w, h, false);
    camera.aspect = w / h;
    camera.updateProjectionMatrix();
    endFraming = chooseEndFraming(h);
    needsResize = false;
  };

  addEventListener('resize', () => { needsResize = true; });
  resize();

  // ---- Input ---------------------------------------------------------------
  const pointer = { x: 0, y: 0 };
  let lookState = createLookAtState();

  if (hasPointer) {
    addEventListener('pointermove', (event) => {
      pointer.x = (event.clientX / innerWidth) * 2 - 1;
      pointer.y = (event.clientY / innerHeight) * 2 - 1;
    });
  }

  // ---- Intro gating --------------------------------------------------------
  let introStart = performance.now() / 1000;
  let introDone = false;

  const finishIntro = () => {
    if (introDone) return;
    introDone = true;
    revealMarquee();
  };

  if (prefersReducedMotion) {
    // §7: the composited final state, static, with the face still faintly there.
    introStart = -Infinity;
    finishIntro();
  } else {
    // The only skip. Mouse and touch have none — the gate is deliberate.
    addEventListener('keydown', () => { introStart = -Infinity; finishIntro(); }, { once: true });
  }

  // ---- Render loop ---------------------------------------------------------
  let paused = false;
  let blinkStart = 2.5;
  let blinkIndex = 0;
  let lastFrame = performance.now();
  let frameBudget = 0;

  document.addEventListener('dialog:open', () => { paused = true; window.__renderPaused = true; });
  document.addEventListener('dialog:close', () => {
    paused = false;
    window.__renderPaused = false;
    // A resize while paused produced no rAF, so the canvas is stale.
    needsResize = true;
  });

  const MAX_FPS_LOW_END = 30;
  const lowEnd = navigator.hardwareConcurrency <= 4;

  function frame(now) {
    requestAnimationFrame(frame);
    if (paused) { lastFrame = now; return; }

    const dt = Math.min((now - lastFrame) / 1000, 0.1);
    lastFrame = now;

    if (lowEnd) {
      frameBudget += dt;
      if (frameBudget < 1 / MAX_FPS_LOW_END) return;
      frameBudget = 0;
    }

    if (needsResize) resize();

    const time = now / 1000;
    const elapsed = time - introStart;
    const intro = prefersReducedMotion || elapsed >= INTRO_DURATION_S
      ? { ...SETTLED_STATE, phase: 'done' }
      : introState(elapsed);

    if (intro.phase === 'done') finishIntro();

    // ---- Camera ----
    const d0 = faceDistance({
      subjectSize: FACE_CALIBRATION.F, fov: FOV, aspect: camera.aspect,
    });
    const startPos = [0, FACE_CALIBRATION.yFace, FACE_CALIBRATION.zFace + d0];
    const { kx, ky } = biasFractions(innerWidth);
    const distance = startPos[2] + (endFraming.position[2] - startPos[2]) * intro.cameraT;
    const bias = frustumBias({
      kx: kx * intro.biasT, ky: ky * intro.biasT,
      fov: FOV, distance, canvasW: innerWidth, canvasH: innerHeight,
    });

    camera.position.set(
      startPos[0] + (endFraming.position[0] - startPos[0]) * intro.cameraT + bias.x,
      startPos[1] + (endFraming.position[1] - startPos[1]) * intro.cameraT + bias.y,
      distance
    );
    camera.lookAt(
      bias.x,
      FACE_CALIBRATION.yFace + (endFraming.lookAt[1] - FACE_CALIBRATION.yFace) * intro.cameraT + bias.y,
      0
    );

    // ---- Compositing ----
    setFaceOpacity(faceParts, intro.faceOpacity, intro.visorOpacity);

    // ---- Behaviours ----
    if (time > blinkStart + 0.12) {
      blinkStart = nextBlinkTime(time, blinkIndex++);
    }
    const blink = blinkState(time, blinkStart);
    faceParts.visorMaterial.emissiveIntensity = blink.emissive;

    const fragments = [idlePose(time)];

    if (hasPointer && introDone) {
      const look = stepLookAt(lookState, pointer, dt);
      lookState = look.state;
      fragments.push(unsplit ? { Root: { ry: look.pose.Neck.ry } } : look.pose);
    }

    applyPose(rig, composePose(fragments), rest);
    renderer.render(scene, camera);
  }

  requestAnimationFrame(frame);
}
```
